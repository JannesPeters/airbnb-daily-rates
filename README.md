# airbnb-daily-rates
Airbnb daily rates

## Airbnb daily-rate bookmarklet

Source: `bookmarklets/airbnb-daily-rate.js`

1. Open the file and copy the single-line `javascript:(...)` snippet.
2. Create a new browser bookmark.
3. Paste the snippet as the bookmark URL.
4. Open an Airbnb search/listing page and click the bookmark.
